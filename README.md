# 🎙️ Aetherix AI Voice Customer Support

An AI-powered Voice Customer Support system built for **Aetherix Technologies** that enables customers to interact naturally using voice while retrieving accurate information from a custom knowledge base through a Retrieval-Augmented Generation (RAG) pipeline.

The project combines a modern customer support website with an intelligent voice assistant capable of answering product, warranty, shipping, return, and troubleshooting queries in real time.

---

## 🚀 Features

- 🎤 AI-powered Voice Customer Support
- 📚 Retrieval-Augmented Generation (RAG)
- 🧠 Google Gemini for intelligent response generation
- 🔊 ElevenLabs Conversational AI for natural voice interactions
- ⚡ n8n automation workflows
- 📂 Google Drive Knowledge Base Integration
- 💬 Real-time customer support experience
- 🌐 Responsive website built with Lovable

## 🧠 System Architecture

```
Customer
      │
      ▼
Aetherix Website
      │
      ▼
ElevenLabs Voice Agent
      │
      ▼
n8n Workflow
      │
      ├── Google Gemini
      ├── Google Drive Knowledge Base
      └── RAG Retrieval
      │
      ▼
AI Response
```


## ⚙️ How It Works

1. Customer opens the Aetherix support website.
2. Customer interacts with the AI assistant using voice.
3. ElevenLabs captures the user's speech.
4. The query is sent to an n8n workflow.
5. Relevant information is retrieved from the knowledge base using a RAG pipeline.
6. Google Gemini generates an accurate response.
7. ElevenLabs converts the response into natural speech.
8. The customer receives an instant voice response.
